# HNO brand assets

The current HNO mark uses a friendly center agent, a three-node halo for multi-agent coordination, and a cyan O-ring wordmark.

## Production assets

- `hno-logo-header.svg` / `hno-logo-header.png`: light-background navigation lockup.
- `hno-logo-header-dark.svg` / `hno-logo-header-dark.png`: dark-background navigation lockup.
- `hno-logo-halo-node-v3.svg` / `hno-logo-halo-node-v3.png`: full light-background brand lockup with tagline.
- `hno-mark-halo-node-v3.svg` / `hno-mark-halo-node-v3.png`: full app and social mark.
- `hno-mark-halo-node-compact.svg` / `hno-mark-halo-node-compact.png`: compact mark for 24px-32px UI surfaces.
- `hno-favicon.svg` / `hno-favicon.png`: simplified 16px-32px browser favicon.

## Palette

- Ink: `#0d0d0d`
- Cyan: `#00ADD8`
- Soft white: `#f7f9fa`
- Coordinator accent: `#ffcf5c`

The SVG files remain the editable source of truth. The PNG files are production exports for browsers, social previews, app icons, and compatibility integrations. `website/public/logo.png` now points to the production HNO mark.

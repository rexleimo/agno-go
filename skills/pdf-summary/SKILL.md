# PDF Summary

## When to use
Use this skill when the user provides a PDF document and asks for a summary, key points, or an overview.

## Steps
1. Extract the document text (title page, table of contents, sections).
2. Identify the document type: paper, report, manual, contract.
3. Extract: main thesis, key arguments/findings, methodology (if any), conclusions.
4. List action items or decisions when present.

## Output format
- Overview (2-3 sentences)
- Key points (bulleted, 5-10 items)
- Action items (if any)
